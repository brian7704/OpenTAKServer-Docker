# Upstream attribution

This distribution integrates and builds the following upstream projects:

- [OpenTAKServer](https://github.com/brian7704/OpenTAKServer), GPL-3.0
- [OpenTAKServer-UI](https://github.com/brian7704/OpenTAKServer-UI)
- OpenTAKServer Docker configuration derived from the upstream OpenTAKServer Docker template

The registration and approval portal in `register/` is an independent integration layer. This repository is community maintained and is not an official OpenTAKServer release.

Source code is provided to meet the corresponding-source requirements of GPL-3.0. Preserve upstream copyright and license notices when redistributing modified versions.
